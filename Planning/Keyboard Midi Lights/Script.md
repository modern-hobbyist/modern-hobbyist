Many many years ago I built this diy keyboard led visualizer or whatever I should call it… that reads the MIDI output from my Keyboard and displays it on an LED strip. 

A lot of things have changed since then. I've moved, several times actually, got a new shop, had a couple kids, shaved off my beard, grew it back again... and somewhere along the way, the LED visualizer got take apart. 

I still have the keyboard, though I haven’t gotten any better at piano in 5 years… i still have that same LED strip and I’ve gotten a whole lot better at designing custom circuit boards, so I figured it’s time to give this project another shot. Let’s get started!
