Well I’ve moved since then, several times actually, and the raspberry pi I built it with got repurposed for a different project so I ended up tearing it apart. I kept my keyboard, though I haven’t gotten any better at piano in 5 years… i still have that same LED strip and I’ve gotten a whole lot better at designing custom circuit boards, so I figured it’s time to give this project another shot.
